How to play

  1. Press Start — tiles light up in a sequence.
  2. Watch carefully. Input is locked during playback.
  3. When it's your turn, tap the tiles in the same order.
  4. Reverse mode: tap them in reverse order.
  5. Each level adds one more step. One mistake ends the game (Classic).

What it measures

  • Sequence length — the longest sequence you reproduced correctly.
  • Accuracy — correct taps ÷ total taps.
  • Recall time — how fast you reproduced the sequence.
  • This is a working-memory style game — not a clinical or medical assessment.

Memory tips

  • Chunk the sequence into groups (like phone numbers).
  • Say the positions in your head as a rhythm or story.
  • Sleep well — memory consolidation happens during sleep.
  • Practice short sessions daily instead of long rare ones.
