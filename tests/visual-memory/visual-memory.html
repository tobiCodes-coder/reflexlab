How to play

  1. Press Start — several tiles light up at the same time.
  2. Memorize where they were. Order does NOT matter.
  3. When the pattern hides, tap all the tiles you remember.
  4. Wrong taps cost a life (Classic: 3 lives). Missed tiles are revealed at round end.
  5. Each level adds more targets; the grid grows at milestones.

Visual vs Sequence memory

  • Sequence Memory tests order — which tile came first, second, third.
  • Visual Memory tests spatial layout — where the tiles were, in any order.
  • This game is a practice experience, not a clinical or diagnostic measurement.

Strategy tips

  • See the pattern as one shape, not separate tiles.
  • Use corners and edges as anchors.
  • Group nearby tiles into clusters.
  • Scan the grid systematically before selecting.
  • Don't guess randomly — wrong taps cost lives.
