How to play

  1. Press Start — a grid of same-colored tiles appears.
  2. Exactly one tile has a slightly different color. Click it.
  3. Correct → next level: bigger grid, subtler difference.
  4. Wrong → you lose a life (Classic: 3 lives).

What the game varies

  • Hue — the color family (red ↔ orange).
  • Saturation — how vivid or washed-out the color is.
  • Brightness — how light or dark the color is.
  • Each round picks one of these (or a mix), and the gap shrinks as levels rise.

Important — not a medical test

  • This is a visual game, not a medical examination.
  • It cannot diagnose color blindness or any vision condition.
  • If you are concerned about your color vision, consult a qualified eye-care professional and use a validated clinical color-vision test.

Tips

  • Scan the grid in rows instead of staring at the center.
  • Squint slightly — brightness differences pop out.
  • Compare corners against each other.
  • Enable the marker aid in Settings if color-only differences are hard for you.
