How to play

  1. Press Start — a number appears.
  2. Memorize it exactly (including any leading zeros).
  3. When it disappears, type the exact digits and press Submit (or Enter).
  4. Correct → the next number gets one more digit.
  5. Wrong → you see a position-by-position comparison (Classic: game over).

How this differs from the other memory games

  • Number Memory — remember an exact digit sequence and reproduce it precisely.
  • Sequence Memory — remember the order of flashing tiles.
  • Visual Memory — remember a simultaneous spatial pattern.
  • Digit-span tasks are common memory exercises — this game is casual practice, not a clinical or IQ assessment.

Memory tips

  • Group digits into chunks of 2–3 (like phone numbers).
  • Repeat the sequence mentally as a rhythm.
  • Turn groups into meaningful numbers (years, ages, dates).
  • Enable "Group digits" in Settings to see chunking in action.
